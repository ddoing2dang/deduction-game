# 6인 Meshy 초벌 베이스 보강 준비 키트

현재 프로젝트 연결은 `ACTIVE_PIPELINE.md`와 `active_sources.json`을 따른다.
새 보강 입력은 `sources/` 6개이며 편집은 별도 `work/CHR_*/` 작업본에서 수행한다.
기존 게임용 FBX 내보내기와 Unity 모델 교체는 보류한다.

## 확인된 사실
업로드된 6개의 Blender 4.4 파일은 각각 오브젝트 데이터 블록 `OB` 1개, 메쉬 `ME` 1개이고, 재질 `MA`, 이미지 `IM`, Armature `AR` 블록은 없습니다. 따라서 단순한 색상 변경이나 텍스처 교체가 아닌 **캐릭터 파츠 분리 및 새 재질/UV/텍스처 제작**이 필요합니다. `.blend` 내부의 색상 속성이나 커스텀 데이터는 본 바이너리 수준 진단으로 판독하지 않았습니다.

## 적용 규칙
- 나즈 NAZ: 분홍 눈, 갈색 장발/핑크 끝, 리본, 핑크 아가일.
- 찌로 JIRO: 노란 눈, 연두/초록 트윈테일, 흰 꽃 2개, 흰 셔츠/초록 리본.
- 마리히 MARIHI: 초록 눈, 웨이브 금발 트윈테일, 검정 리본, 따뜻한 갸루 피부톤, 검정/흰색/골드.
- 마또 MATTO: 빨간 눈, 긴 백발, 검정 베레모, 딥레드 큰 목 리본, 플리츠 스커트.
- 보키 BOKI: **회색 눈**, 버건디 단발, 검정 상의/스커트, 베이지 오버사이즈 소매.
- 문이레 MUNIRE: 보라 눈, 긴 보라 머리, 나비 장식, 흰 퍼프소매, 보라/검정 의상.

## 준비 작업 실행
1. 이 키트 압축을 해제합니다.
2. `sources/` 폴더를 만들고 6개 원본 `.blend`를 복사합니다. 원본 자체는 절대 수정하지 마세요.
3. Blender 4.4 이상이 설치된 PC에서 `run_on_windows.bat`을 실행합니다. `blender` 명령이 PATH에 없다면 BAT 상단의 `BLENDER`에 Blender.exe 전체 경로를 적습니다.
4. `refinement_work/`에 캐릭터별 `_REFINEMENT_WIP.blend`와 `_AUDIT.json`이 생성됩니다.

### 이 스크립트가 하는 일
- 원본을 덮어쓰지 않고 새 `.blend`로 저장.
- 파일 안의 메쉬, UV, 버텍스 그룹, ShapeKey, 재질 상태를 JSON 진단.
- 6명 각각의 **눈색 LOCK이 정확한** PBR 컬러 재질 라이브러리 추가(재질 이름에 `LOCK_` 표기).
- 작업 중 상태를 `WIP`로 표시하고 실제 조형/리깅이 안 됐음을 명확히 남김.

### 이 스크립트만으로 해결되지 않는 일
- 눈/코/입 형태 조각, 캐릭터별 비율 수정.
- 메쉬 표면에서 실제 홍채 영역 지정과 색 적용(현재 한 덩어리 메쉬여서 무작위 색 적용 금지).
- 얼굴/머리/의상/신발 파츠 분리, UV 제작 및 텍스처 페인팅.
- 리토폴로지, 리깅, 표정 ShapeKey, 최종 3D 품질·Unity 플레이 검증.

이 키트는 원본 훼손 없이 준비와 정밀 검사부터 진행하는 **첫 단계**입니다. 최종 리파인 완료로 보아서는 안 됩니다.
