# 대저택 Visual Gold — 입구 장식문 추가 작업지시

## 현재 요청 (2026-10-29)
기존 Visual Gold 대저택 중앙홀에 **저택 외부 정문처럼 보이는 문 1개**를 만든다. 정문은 **외관 연출 전용**으로, 실제 이동이나 방 전환은 발생하지 않는다.

## 필수 작업 절차
1. 로컬 `art/Mansion/VisualGold/Mansion_VisualGold.blend`를 Blender에서 열고 먼저 백업한다.
2. 기존 맵 지오메트리 및 중앙홀 출입 방향을 검사한다. **실제 정문을 놓을 벽면을 확인한 뒤** 배치한다. 임의 월드 좌표나 코드상 가정한 방 배치를 사용하지 않는다.
3. 외부의 중앙 진입로에서 중앙홀로 들어오는 듯 보이도록 웅장한 **장식용 양개문 한 개 세트**를 구성한다. 목재 문짝 2개, 황동 손잡이, 문틀/몰딩, 양옆 벽등, 문 위 장식은 무료 CC0 재질/기존 에셋 활용. 모델은 시각적 문으로만 유지하고 실제 구멍이나 경로는 생성하지 않는다.
4. 3D 반 탑뷰와 사이드뷰에서 문 형태가 명확히 보이고, 컷어웨이로 사라지지 않도록 적절한 비게임플레이 컬렉션에 배치한다. 주변 외관/진입로와 시각적으로 연결한다.
5. **이 문에는 DoorID, 문 이동 트리거, Collider를 통한 통과, 상호작용 포인트, NavMesh 링크, 방 전환 이벤트를 부여하지 않는다.** 이벤트용 통로·기존 11개 연결·비밀통로 변경 금지.
6. 렌더 검토: 정문 외부 전경, 중앙홀에서 본 정문, 반 탑뷰, 3D 사이드뷰의 실제 Blender 캡처를 저장한다.
7. 교차 확인: 기존 9개 방 / 11개 연결, 양방향 이동 22회, 비밀통로 왕복, 54 StandPoint / 9 ActionPoint, 3단 줌 및 컷어웨이 회귀를 기존 프로젝트 검증 절차에 따라 실행. 캐릭터 179개 파일 변경하지 않는다. **기존 검사 수치를 실행하지 않고 통과로 주장하지 않는다.**
8. 최종 Blender, FBX, 렌더 캡처, 검증 리포트 저장 후 GitHub 커밋. 저장 어려운 대형 바이너리는 기존 프로젝트의 Git LFS/Release 정책을 따른다.

## 비주얼 기준
- 기존 사용자 승인 시안의 고급 고딕·빅토리안 대저택 분위기를 참고하되, 컷신용 구도는 실제 작업 파일 렌더로 판단한다.
- 동물의 숲은 정돈된 모델 형태/색 조화만 참고. 게임 분위기는 진지한 머더 미스터리.
- 캐릭터 제작/수정은 이번 작업 범위에서 제외.

## 현재 상태 구분
- 이 문서는 작업 요청 및 검증 기준이며 **실제 Blender에 문을 생성·적용했다는 의미가 아님**.
- 현 채팅의 GitHub 커넥터에서는 로컬 `.blend` 원본 및 실제 렌더 이미지에 접근할 수 없으므로 Blender 수행 단계는 로컬 Codex/Blender 환경에서 진행해야 한다.
