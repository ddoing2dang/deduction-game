# 대저택 계단 배치 재검증 — 2026-10-24

이번 판정은 이전 이동 성공 기록과 분리했다. Blender MCP로 원본을 수정하고 FBX를 재내보낸 뒤, Unity의 실제 Play Mode Camera.main 캡처를 직접 검토했다. OS 입력, 자동 클릭, 커서 제어, 외부 GUI 자동화는 사용하지 않았다.

## 기존 배치의 문제

- 중앙홀 계단은 작은 독립 발판으로 끝나 갤러리와의 관계가 약했다.
- 서비스 계단은 기존 Entry를 유지하려다 긴 외곽 우회 구간과 별도 문틀이 생겼다. 방의 서비스 하강구보다 외부 연결 장치처럼 읽혔다.
- 이전 캡처는 근접 줌 위주였고, 이동 성공이 건축 배치 합격을 뜻하지 않았다.

사용자 피드백에 따라 중간의 U자 계단실 안은 폐기했다. 최종안은 두 방의 벽 쪽에 직선 하강 계단을 두고 불필요한 독립 문틀을 없애는 방식이다.

## 최종 형상

좌표는 Blender의 (X, Y, Z-up), 단위는 m이다.

| 대상 | 위치·방향·형태 |
| --- | --- |
| 중앙홀 | 후면 서쪽에 배치. (-1.5, 5.5, 0) 부근에서 서쪽으로 올라 (-4.5, 5.5, 2.16)의 발판에 도착한다. 서쪽·후면 벽을 따르는 L자 갤러리와 연결하며 상층 문이나 새 RoomNode는 만들지 않았다. |
| 식당↔보일러실 | 식당 서쪽 벽의 하강구. (-15.06, -5.2, 0) → (-15.06, -11.8, -4)의 직선 계단, 하부 발판에서 동쪽으로 돌아 보일러실 남쪽 벽 개구부로 들어간다. |
| 주방↔와인저장고 | 주방 동쪽 서비스 가장자리의 하강구. (4.95, -5.7, 0) → (4.95, -12.3, -4)의 직선 계단, 하부 발판에서 서쪽으로 돌아 와인저장고 남쪽 서비스 개구부로 들어간다. |

서비스 계단은 폭 1.6m, 수평 길이 6.6m, 높이 차 4m, 23개 단으로 구성했다. 단높이는 약 174mm, 디딤판 길이는 약 287mm다. 상부 발판은 1.6×1.6m이며, 하부는 방향 전환용 발판과 폭 1.6m의 짧은 진입 구간을 둔다. 하부 난간은 회전 입구를 막지 않도록 발판 바깥에서 시작한다.

기존 서비스 계단의 독립 문틀은 모두 제거했다. 지상 바닥 개구부에는 낮은 보호벽·난간을 두고, 지하는 실제 벽의 개구부와 연결했다. 주방 첫 계단 위를 가로지르던 기존 서비스 통로의 끝 난간·하부 보 일부만 국소적으로 잘라 접근을 열었다. 해당 통로의 DoorID와 게임 연결은 유지했다.

## 검증 근거

- Blender: 상면·정면·측면·사선 및 플레이 카메라 방향의 근접/기본/전체 줌 21장. 계단이 방 가장자리의 하강구로 읽히며 독립 문틀이 없고, 중앙홀 계단은 벽과 갤러리로 연결되는 것을 직접 확인했다.
- Blender 메시 검사: 계단/벽 교차 0, 머리 공간 장애 0(2.05m 검사), StandPoint 간섭 0/54, 허용한 네 Entry 외 기준점 위치 변화 0. 발판과 난간은 다각도 캡처로 확인했다.
- Unity: Room 1/4/5/7/8의 실제 Play Mode Camera.main에서 기존 회전·위치 기준을 유지한 9/19/32 줌 15장과 추가 진단 시점 20장. 실제 CharacterActor를 각 진입점에 배치한 최종 캡처도 검토했다.
- 실제 이동: 중앙홀 장식 계단 앞 지상 동선 양방향, 식당↔보일러실 양방향, 주방↔와인저장고 양방향, 기존 응접실↔주방 양방향. 서비스 계단은 강제 중간 경유점 없이 하나의 NavMesh 경로로 검사했다. 각 경로 모서리가 설계된 계단/발판 중심선 1.1m 안에 있고, 경로 길이가 설계 동선 길이+2m 이내인지 확인했다.
- 실제 CharacterActor 이동 중 벽·난간 삼각형 메시와 캡슐 관통 검사, off-mesh link 미사용 검사, 프레임별 회전 연속성 검사 통과. 관측 최대 회전은 프레임당 14.4도이며 기존 720도/초 회전 상한을 넘는 점프는 없었다.
- 9 RoomNode, 11 LOCK 연결, 6 CharacterActor, 54 StandPoint, 9 ActionPoint와 이벤트 계층 보존. 11개 연결의 NavMesh 경로 회귀 검사 통과.
- 기존 싱글플레이 E2E의 전체 게임·집중 규칙 검사 2,461개 통과.
- 컷어웨이: 렌더링만 숨기고 물리 Collider는 유지한다. 와인저장고에서 주방 바닥은 숨기되, 0.5m의 가장자리 겹침 때문에 중앙홀 바닥 전체가 사라지던 현상을 수정했다. 최종 카메라 검사에서 중앙홀 바닥 유지/주방 바닥 숨김/Collider 유지도 확인한다.

시각 판정: 계단 위치가 저택의 실제 건축 구조로 자연스럽게 보인다. 두 서비스 계단의 하강구는 방 중앙이 아닌 벽면 서비스 가장자리에 있고, 중앙홀 계단은 독립 단상이 아니라 벽을 따라 갤러리에 연결된다. 이 판정은 NavMesh 성공과 별도로 캡처를 검토한 결과다.
