# 탐정 수첩 — 장소 단서 A/B 선택·상세보기 UI 기록

이 디렉터리는 2026-11-14 사용자가 요청한 **14개 장소 단서 UI 화면의 제작 내역과 슬롯 규격**을 보관합니다.

## 화면 규격
- 수첩 개인형 디자인: 짙은 가죽, 종이, 버건디 강조. **장미 문양/대저택 테마 장식 없음**.
- **왼쪽**: `101·102·103·201·202·203·204호` 일곱 줄, 각 줄 `단서 A`/ `단서 B` 선택.
- **오른쪽**: 클릭한 단서 한 개의 그림, 발견 출처, 유형, 상세 설명과 조사 메모.
- 미획득 상태: `?` / `미획득`. 선택 상태: 버건디 테두리. **14개 화면은 각각 다른 단서가 선택된 상태**.
- 원본 출력 규격: 각각 **1672×941 RGB PNG**, 총 14개.
- 흉기 목록은 별도의 **흉기 탭**에 배치하고, 장소 단서 탭과 혼합하지 않음.

## 데이터·승인 주의
- 이미지에 적힌 찢어진 메모·혈흔 등의 제목과 설명은 **화면용 예시**다. 실제 사건 진실/증거, 방 배치, 범인의 정답, 흉기 배치를 승인하거나 고정한 것이 아니다.
- 범인과 흉기 배치는 회차별로 달라질 수 있으므로 **발견 여부·단서 설명·출처 등은 Unity에서 동적으로 표현**해야 한다. 이 14개 완성 화면 PNG는 UI 시안이지 개별 버튼/문자 레이어가 분리된 Unity 프리팹이 아니다.
- 기존 Unity 씬, 원본 에셋, 흉기 카탈로그, 본편 대사는 변경하지 않음. 게임 기능·Play Mode·빌드 확인 없음.

## 현재 GitHub 저장 범위
**이 README와 `location_clue_ui_manifest.v1.json`만 GitHub에 기록**했다. 
대화에서 제작된 실제 PNG 14개와 ZIP 아카이브는 **GitHub 업로드 미완료**이며, 원본이 업로드된 것처럼 표시하면 안 된다.
원본 14개 PNG의 파일명/슬롯/축약 SHA-256은 manifest에 기록했으며, 추후 해당 바이트를 업로드할 때 대조해야 한다.
