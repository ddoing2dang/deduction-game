# 탐정 수첩 — 인물·진술 선택/상세 화면 6종

**확정 디자인 기록 (2026-11-14).** 6명 중 한 명을 왼쪽에서 고르면 오른쪽에 해당 인물의 정보를 보여주는 **개인 탐정 수첩 UI**입니다.

## 디자인 규칙
- **장미 장식·장미 대저택 전용 장식 사용 금지.** 개인 가죽 수첩·아이보리 종이·절제된 버건디 색감 사용.
- 왼쪽: 인물 6명 목록. 선택한 인물만 버건디 배경 강조.
- 오른쪽: 선택 인물 요약, 사건 당시 알리바이, 피해자와의 관계, 의심 인물에 대한 진술, 탐정 메모.
- 획득하지 않은 진술: `?` / `미획득`. 플레이어가 실제 확인한 사실만 표시.
- 공식 인물·호수: **101 마도은, 102 진소율, 103 김보희, 201 마연희, 202 나지수, 203 문이현**.
- PNG 시안은 1672×941 RGB 정적 화면 6장. **초상화는 임시 실루엣**이므로 게임용 원본 공식 초상화로 교체/연결해야 함.

## 회차별 랜덤 사건 대응
범인과 사건 사실이 매 회차 달라질 수 있음. **나이·직업·증언·발견 여부·알리바이 등 임의 사실을 이미지에 고정하지 않음.** 인물별 3개의 정보 항목도 질문별로 따로 해금하며 미획득 항목은 블라인드 상태로 유지. 범인/정답 여부를 UI에서 표시하지 않음.

### GitHub 업로드 상태
이 커밋에는 **README와 manifest JSON 두 텍스트 파일만** 들어 있습니다. PNG 6장·미리보기 JPG·ZIP의 원본 바이너리 업로드는 아직 완료되지 않았으며, manifest의 SHA-256으로 이후 원본 일치 여부를 확인할 수 있습니다. 이전에 만든 장소 단서 14종 UI와 흉기 UI도 임의 수정하지 않았습니다.
