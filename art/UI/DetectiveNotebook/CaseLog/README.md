# 탐정 수첩 — 사건 기록 5일 × 오전·오후 10턴 UI

사용자가 승인한 **하나의 펼친 가죽 수첩** 디자인이며, 별도 떠 있는 두 번째 화면이나 장미 장식이 없습니다.

## GitHub에 저장된 실제 이미지 에셋
- `Screens/D1_AM.svg` ~ `Screens/D5_PM.svg` : 10개 시간대가 **왼쪽**에 있고, 선택한 시간대만 강조하며 **오른쪽**에 요약·단서·진술·노트가 있는 벡터 SVG 이미지 10장.
- `Overlays/InferenceChoice.svg` : **추리 메모 선택** 버튼을 눌렀을 때 나타나는 선택창 이미지 1장.
- `States/InferenceSaved.svg` : 실제로 선택된 메모와 관련 근거를 합쳐 보여주는 기록 상태 이미지 1장.
- **SVG는 실제 이미지 파일**로 GitHub에서 열 수 있습니다. PNG가 필요한 Unity 사용처에서는 SVG를 PNG로 변환하거나 SVG 지원 패키지로 임포트해야 합니다.

## 확정된 레이아웃/경험
1. **좌측 1~5일차 × 오전·오후 총 10칸**. 열람하지 않은 턴은 `미진행` 등으로 표시합니다.
2. 선택한 시간대의 **해당 턴에 방문한 객실 1개**와, 실제로 얻은 정황·진술의 요점만 오른쪽에 표시합니다. 시계 시간은 표시하지 않습니다.
3. 흉기/장소 단서 탭 전체 목록을 사건 기록 화면에 중복하지 않습니다. 관련 출처를 짧은 태그로만 연결합니다.
4. 기본 화면에는 추리 **선택지 자체는 보이지 않으며** `추리 메모 선택` 버튼만 보입니다.
5. 버튼 클릭 시, **플레이어가 실제로 가진 증거**로 뒷받침할 수 있는 2~4개 의문문 후보(자료 부족 시 0개)를 보여줍니다. 클릭·기록하면 **선택한 의문 + 연결된 원문 자료의 출처**를 노트 형식으로 보관합니다.
6. 플레이어가 입력/선택하지 않은 추리 문구를 임의 기록하지 않습니다. 정답·범인·수법·흉기에 대한 힌트나 자동 모순/진실 판정을 표시하지 않습니다.
7. 회차별 범인/도구/정보/진술이 바뀌어도 UI는 동일합니다. **10개 SVG는 선택 상태 시안**이며 텍스트·발견 기록은 고정 게임 데이터로 쓰면 안 됩니다.

## 상태 및 주의
- `D1_AM.svg`와 `InferenceChoice.svg`의 일부 텍스트는 **UI 제작 예시**로서 승인된 사건 진실이 아닙니다. 단서를 실제로 얻기 전에는 표시하지 않습니다.
- 현재 저장한 것은 **SVG 화면 에셋, 화면 규격 JSON과 문서**입니다. PNG 바이너리 및 Unity Prefab/씬 연결·기능 테스트·빌드는 미수행입니다.
- 텍스트/초상화/방 사진/기록 카드가 별개의 런타임 UI 요소가 되어야 선택·스크롤·저장 동작이 가능하며, 전체 화면을 한 장의 그림으로 만드는 것만으로 Unity 기능이 완성되지는 않습니다.
- 기존 게임 코드 및 씬은 변경하지 않습니다.
