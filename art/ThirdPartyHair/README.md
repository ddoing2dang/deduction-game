# Free commercial-use character hair — verified sources

This directory is an **asset holding area**, not an automatic change to any approved game character.

## Included import: VRoid HairSample_Female (CC0)

- Publisher: VRoid Project / pixiv Inc.
- Official CC0 confirmation: https://vroid.pixiv.help/hc/en-us/articles/4402614652569-Do-VRoid-Studio-s-sample-models-come-with-conditions-of-use
- Download mirror used for reproducibility: https://github.com/madjin/vrm-samples/blob/e16eb187100149a315ad92c3c9968f1d5baa6c7d/vroid/beta/HairSample_Female.vrm
- License: **CC0-1.0**, including commercial use, adaptation and redistribution. The official license confirmation specifically names `HairSample_Female`.
- Expected file: `HairSample_Female.vrm` (17,518,216 bytes; pinned source Git blob SHA-1 `0e5235f9a7972fbcbceb74960479b208c27a8707`).
- This is a **full VRM sample avatar containing hair**, not an extracted standalone hair preset. Extract/adapt only its hair in Blender 5.0.1 using a compatible VRM importer.
- `fetch_cc0_hair.py` downloads the pinned source and refuses a byte mismatch. No account or payment is needed.

## Game integration safety

- Do **not** overwrite `art/Characters/CHR_MATTO`, any approved character models, or mansion/game rules.
- No Unity prefab changes, builds or rig replacements are part of this asset import.
- For BOKI, keep the validated 162-bone VRoid body rig and approved body proportions; a candidate hairstyle must be fitted and head-bound in a separate working copy and visually compared to the approved burgundy bob.
- BOOTH hair presets allowing *commercial use but prohibiting redistribution* are **not copied into this public repository**. Examples of excluded assets: maruko's free original hair and Kattensia Short Twintails.
- License and availability verified on 2026-10-31; check upstream again before release.
