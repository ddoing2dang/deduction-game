# 사건파일 No.464 — HOTEL H00 프리미엄 중앙 로비 제작 브리프

**상태: 작업 지침/품질 기준만 작성. 실제 Unity 씬은 아직 미제작.** 2026-11-10. 화면 구성은 3D 쿼터뷰이며, 대사/조사 클로즈업 모두 가능한 구조를 목표로 한다.

## 제작 범위
- 현재 맵 룰: 호텔 1F **공동 로비 1개 + 101~103**, 2F **201~204**. H00은 **LOBBY**, 별도 조사 방 개수 추가 금지.
- 미술 원형: 짙은 월넛, 버건디, 금빛 브라스 장식, 차가운 대리석 바닥, 곡선 몰딩, 높이가 느껴지는 현관, 로비 중심 계단.
- 쿼터뷰에서 한눈에 중요한 구조가 보이고 인물·증거 인터랙션의 가독성을 유지. 실제 룸 비례/카메라 각도는 첫 아트 승인을 위해 조정 가능.

## 레벨 구성용 초기 치수(미확정 시안)
- 로비 내부 약 14m x 10m, 층고 5m 내외를 시작 레퍼런스로 제안. 사용자 확정 수치가 아니므로 모델 실제 크기에 맞춰 조정.
- 중앙 메인 계단(로비 정체성의 핵심), 양쪽 다른 높이의 아치/패널 조각, 한쪽 리셉션 카운터, 반대편 응접 구역.
- 101/102/103 방문 통로와 상부 연결 계단은 게임 레이아웃을 침범하지 않음. 복도와 계단은 **조사 방으로 새로 계산하지 않음**.
- 전면 벽/상부 난간은 카메라 각도에서 부분 컷어웨이하여 바닥, 문과 조사 가구가 완전히 가려지지 않게 함.

| 바닥 | 대리석 타일 정렬과 줄눈, 스테인/러그의 접지, 반사량·요철 차이 | 매끈한 한 장 바닥, 같은 반복 패턴 |

## PBR 소재 세트
1. 검붉은 월넛 나무 패널: 결의 방향/러프니스·마모 영역 구분, 정교한 노멀과 매트 글로스.
2. 적갈색/아이보리 대리석: 층리/줄눈/표면 미세거칠기, 바닥·난간 접촉면 섀도우.
3. 브러시 브라스: 무조건 거울처럼 만들지 말고 금속도/러프니스/모서리 하이라이트 물리 일관성.
4. 버건디 벨벳/가죽: 장식 스티치·접힘 형태와 표면 비등방/거칠기 차이.
5. 흰 석재·석고 몰딩: 모서리 베벨, 완만한 AO/접지, 틈의 음영.

Poly Haven 등 CC0 PBR 소스를 품질 심사 후 선별. 의미 없는 4K 채우기보다 카메라에 가까운 표면의 텍셀 밀도와 UV/머티리얼 일관성 우선. 상용 모델을 임의로 GitHub에 업로드하지 않음.

## 기존 저장소 자산 활용 판단
- `art/Environment/room_profiles_24.v1.json`의 H00 hero인 `stairs-stone-square.obj`와 각종 소파/러그는 **비례/배치 및 대략적 분위기 참고용 소스**.
- 품질이 낮으면 그대로 사용하지 않는다. ProBuilder에서 구조 수정하거나 Blender에서 새 지오메트리·고급 커스텀 몰딩/난간/실제 재질을 제작.
- 실제 24공간에 같은 책장/램프를 돌려쓰더라도 **대표물, 방 전체 실루엣, 소재, 소품군, 조명**의 차이가 필요.

## 제작 순서 / 승인
1. Unity 프로젝트와 GitHub/Unity MCP 연결 확인(로컬). 패키지 경로, 머티리얼, 소스 모델 로드 여부 확인.
2. H00 부지·문 위치·계단/상부 연결 구조를 ProBuilder로 편집. 이 그레이박스는 최종품이 아니다.
3. 고품질 건축 및 가구 원천 모델 제작/승인, Blender로 곡면·몰딩·UV·베벨 등 보강.
4. PBR 표면/고해상도 소스/라이팅 세트 구축. 씬 복잡도는 고정 카메라 실제 비중에 맞춰 제어.
5. 카메라 프레임과 벽 cutaway 조정, 증거 열람 시 카메라 포커스와 UI 오클루전 검토.
6. `Case464MapWorkshop` 품질 프리플라이트에 승인된 프리팹만 등록, 새 리뷰 씬 생성. 체크 통과는 '진짜 고품질 인증'이 아님.
7. 실제 화면 1920×1080 및 확대 샷에서 사용자 승인까지 반복 디자인. **동일 기술 오류 2회는 수정 중지→준비물 진단**. 실제 테스트/베이크는 사용자가 별도 승인한 시점.
8. H00 품질 승인 후 나머지 HOTEL 7방 확장. 각 방은 복붙 후 단순 색만 변경하지 않음.
