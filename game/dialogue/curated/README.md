이 폴더는 **편집·검토용 선별본**이며 Unity 게임에 자동 연결된 데이터가 아닙니다. 기존 원본 JSON과 228+486줄 대사는 **수정하거나 삭제하지 않았습니다**.

## 선별 기준

- 마또는 활발하지만 위급 상황에선 진지하게, 찌로는 털털하고 배려 있게, 마리히는 문학적인 표현을 드물게, 나즈는 차분하고 단호하게, 보키는 자연스러운 일상 대화체로, 문이레는 조용하지만 자기 의견을 지키는 말투로 작성된 원문 우선.
- **공통 대사:** 첫 만남, 재방문, 사건·피해자 반응, 알리바이·시각·목격·관계·방·물건·수법·기록 질문, 증거 제시/모름, 근거 없는 추궁·고발, 신뢰 변화, 반복·불분명한 질문, 휴식·작별·조심스러운 답변·위로를 중심으로 26상황만 남겼습니다.
- **테마 사건 대사:** 각 세부 사건(9개)에 대해 증거 반응은 NPC 6명 전원 보존, 두 번째 대사는 동선 질문 3명 + 흉기 질문 3명씩 선택. NPC별로 선택 종류를 분산해 한 인물에 한쪽 질문만 몰리지 않도록 조절했습니다.
- 테마별 **동선·현장 방 번호**를 유지하고 12종 무기 종류는 모든 테마에서 동일합니다. 사건 설계 문서의 특정 무기 추천은 확정된 살해 도구가 아닙니다.
- 기존 대사 원문을 삭제·임의 개작하지 않고 우선 **선택만** 진행했습니다. 편집 승인 시 수정문은 별도 고유 ID로 관리해야 합니다.

## 사용 금지·승인 조건

1. 이 선별본은 **아직 플레이 가능한 사건 증언팩이 아닙니다**. 사건 사실, NPC별 지식, 실제로 제시된 증거, 물증과 시간표가 검증되고 작가가 승인한 뒤에만 선택할 수 있습니다.
2. 원본 `requiredState`, `requiredFactIds`, `requiredPresentedEvidenceIds` 조건은 생략·완화하면 안 됩니다. 승인 전 실시간 AI로 신규 NPC 대사를 만들지 않습니다.
3. 9세부 수법은 후보안, 최종 고발 정답 축은 **범인 + 4대 수법 중 하나 + 흉기**로 유지합니다.
4. 특히 `M02_V2` 낙하물 충격형은 공간·물리·동선 검증 전 비활성 상태입니다.
5. 흉기 실물은 **6명 개인실**에만 두며, 로비/현장은 흔적·기록만 둡니다. 동일 품목이 두 방에 있어도 다른 물리 실물입니다.
6. 원본 출처: `../npc_dialogue_catalog.v1.json`, `../method_variant_theme_lines.v1.json`, `../../cases/weapon_method_catalog.v1.json`, `../../maps/theme_room_layouts.v1.json`.
7. **기능 테스트·Unity 빌드·게임 코드 수정 없이 JSON/문서만 저장**합니다.
