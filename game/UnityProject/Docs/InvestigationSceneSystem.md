# NPC 증거 조사 화면 v1 — 맵 제작 전

2026-11-10 · `mystery` Windows PC · GitHub 코드 및 JSON 에셋

## 게임에서의 화면 흐름

1. 기존 대화창의 **현장 조사** 버튼을 열면 장소 목록이 표시된다. 기존 **수사 수첩** 버튼과 별도로 만들었고 한쪽을 열면 다른 쪽을 닫는다.
2. 장소 선택 → 조사 지점 선택 → **자세히 조사**를 눌러 해당 물건·흔적의 조사 설명을 읽는다.
3. 증거로 정의된 지점이면 **수첩에 기록**을 눌러 획득한다. 증거가 없는 지점은 묘사만 보여 주고 획득 버튼은 활성화하지 않는다.
4. 획득한 증거는 `DialogueInterrogationAdapter.UnlockEvidence(id)`를 통해 기존 수사 수첩의 증거 목록에 동기화된다. NPC 심문에 필요한 단서도 같은 인벤토리를 사용한다.
5. 필요한 선행 단서가 없으면 조사 결과를 공개하지 않는다. 이때 **선행 증거의 이름이나 미획득 증거 ID를 플레이어에게 공개하지 않는다**.
6. 동일 증거는 두 번 획득하지 않는다. 장소/지점을 다시 열어도 `확보 완료`로 표시된다.
7. 크루즈·음악방송은 사건 내용이 아직 미작성되어 목록이 비어 있는 사건별 JSON 템플릿만 생성했다.

## 대저택 사건 조사 장소 9곳

| 장소 | 조사 지점 | 연결된 증거 |
|---|---|---|
| 현관 홀 | 공지판의 종이, 멈춘 대형 시계 | 회계 공개 초대장 (시계는 일반 관찰) |
| 기록 서고 | 봉인된 회계 서류함, 낡은 상자 | 회계 사본 (초대장 필요) |
| 분전반 기록실 | 자동 차단기 기록 | 정전 기록 |
| 보안 기록실 | 출입 카드 단말, 비상전원 CCTV | G3 출입 기록, CCTV (정전 기록 필요) |
| 온실 관리실 | 카드 지급 대장, 작업 장갑 선반 | G3 지급 대장 (장갑은 일반 관찰) |
| 온실 연결 통로 | 젖은 바닥 자국, 문 경첩 | 흙 발자국, 실밥 (흙 발자국 필요) |
| 시계 공방 | 시계 정비 노트, 작업 사진 목록 | 시계 고장 기록, 작업 사진 |
| 주방 | 식자재 발주표 | 주방 발주 기록 |
| 서재 | 책상 아래 물건 | 청동 책받침 |

**총 9개 장소, 15개 조사 지점, 12개 수집 가능한 증거.** 기존 대저택 `Mansion.json`의 12개 증거 ID를 **모두 1:1로** 연결했으며 잠정 범인, 심문 진술과 지목 규칙은 변경하지 않았다.

## 승인·보안·작업 경계

- 사건 초안 `Mansion.json`은 **`approved: false` 그대로 유지**. 런타임에서 조사 장소와 증거는 잠겨 있고, 작성자 승인 전에는 NPC 답변과 범인 지목도 활성화되지 않는다.
- 단서 **등록/해제는 오직 UI 조사 동작 후** `UnlockEvidence`를 호출한다. 질문 입력만으로 단서를 획득할 수 없다. 아직 맵이 없으므로 2D 조사 화면은 향후 맵 상호작용의 대체 진입점이다.
- 사건 데이터의 진위를 보장하는 것은 작성자 승인 절차다. JSON에는 미리 정한 사건의 내용을 담되 숨겨야 할 증거는 조사를 거칠 때만 확인하도록 했다.
- 3D 모델, 맵, 배경 이미지를 추가하지 않았다. 기존 NPC 원본 PNG 6장, 대화창 프레임 3종, TMP 폰트 원본과 미리보기 씬은 변경하지 않았다.
- **GitHub에서 소스와 직렬화 링크만 확인**했다. 로컬 Unity 에디터·컴파일·Play Mode·기능 테스트·EXE 빌드는 이번 작업에 사용하지 않았다.
- 사건 내 인벤토리는 현재 실행 세션 메모리에만 저장되며 저장/불러오기는 아직 구현하지 않았다.
