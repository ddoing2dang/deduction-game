# 대저택 제1사건 — 멈춘 시계의 초대장

> **제작자용 스포일러 문서 / 사용자 승인 전 초안** · Unity 맵은 만들지 않음

## 사건의 진실

대저택 소유주이자 재단 운영자인 **서현석**이 21:15 서재에서 숨진 채 발견된다. 그는 21:30 재단의 후원금 사용 내역을 공개할 예정이었다. 정전(21:06~21:12) 사이 누군가 온실과 서재를 잇는 서비스 문으로 드나들어 청동 책받침으로 피해자를 공격했다.

**잠정 범인: 진루나(인덱스 4).** 희귀식물을 지키려고 후원금을 승인 없이 온실 설비비로 전용했다. 사실을 공개하려던 관장과 21:09 다투다가 공격했고, 21:11 서비스 문으로 돌아갔다. 처음에는 온실에만 있었다고 거짓말한다.

정전은 자동 차단기 고장으로 우연히 발생했으며 범인이 조작한 것이 아니다. 현관 시계의 20:17은 **사건 전날** 고장으로 멈춘 시각이므로 살해 시각을 표시하지 않는다.

## 질문·정답 구조

- `Mansion.json`: **NPC 6명 × 질문 주제 13개 = 78개** 작성자 초안 진술.
- 기본 질문: 알리바이, 사건 시간, 목격, 인물 관계, 동기, 단서.
- 증거 관련 질문: 정전, 고장 시계, G3 출입 기록, 흙 발자국, 회계 사본, 청동 책받침.
- 마지막 대면 `confront`: `m01_lock` + `m01_mud` + `m01_ledger` 세 단서 획득 후만 접근 가능.
- 진루나만 5개의 초안 거짓 진술(알리바이·시간·목격·동기·증거) 사용. `m01_lock`, `m01_mud`, `m01_ledger` 획득 시 해당 진술을 사실로 전환.
- **범인이 아닌 인물은 모두 사실에 맞는 진술만 한다.** 다만 문장의 사실 여부는 게임 코드가 자동으로 판단할 수 없으므로 최종 내용 검수는 필요하다.
