# Deduction Game Unity Project

Unity 6.3 LTS production project.

## Open
Open this folder itself in Unity Hub:

`game/UnityProject`

The editor bootstrap creates `Assets/_Game/Scenes/Game.unity` automatically on the first successful script compile.

## Current playable core
- 6 players fixed
- Human + 5 AI
- Pre-R1 setup movement: 3P
- R1 starts only after all six setup placements finish
- R1+ base movement: 2P
- Nine-room graph
- Click room blocks to move
- Human end-turn button
- AI turns resolve automatically
- R1-R12 progression

Next implementation: cards, culprit role, suspicion/cooperation, private information, deduction, events and abilities.
