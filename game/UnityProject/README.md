# 마또 머더미스터리 — Unity 프로젝트

이 폴더(`game/UnityProject`)는 기존 Unity 제작 프로젝트지만 **기존 런타임은 구형 카드·턴·PvP 게임 코드**다. 새 게임은 문서 기획 단계이고 아직 Unity 전환이 완료되지 않았다.

최신 기준:
- [게임 규칙](../../GAME_RULES.md)
- [사건 생성·증거 설계](../../CASE_DESIGN.md)
- [쿼터뷰 2.5D 아트 제작](../../PRODUCTION_STANDARD_2_5D.md)
- [Codex 지침](../../AGENTS.md)

**새 목표:** 플레이어 탐정 1명 + 고정 NPC 용의자 6명(매 판 랜덤 범인), 장소/물증 조사 + NPC 심문 + 모순 대조 + 3항목 최종 고발.

현재 Unity 코드와 예전 씬/오브젝트/아트는 구현 대상을 선택하기 위한 Legacy 참고 원본이다. 작업자에게 새 룰로 이미 구현되었다고 안내하거나 기존 6인 PvP UI/플레이를 유지할 이유로 쓰지 않는다.

확정 전에 Unity 씬을 덮어쓰거나 기존 소스를 무차별 삭제하지 않는다. 사용자가 별도 요청하지 않은 기능 테스트, EXE/APK 빌드, 배포는 하지 않는다.
