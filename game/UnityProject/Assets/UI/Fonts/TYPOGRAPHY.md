# 대화창 서체

| UI | TMP SDF |
| --- | --- |
| NPC 이름 | MaruBuri SemiBold |
| NPC 대사 | MaruBuri Regular |
| 질문 입력 텍스트와 자리표시자, 대화 기록 본문, 안내 | Pretendard Regular |
| 기록 제목과 전송 버튼 | Pretendard SemiBold |

원본 OTF 네 개와 동적 TMP SDF 네 개가 이 폴더에 있습니다. 프리팹에 연결된 에셋은 Unity 6000.3.26f1에서 생성했습니다. Unity Edit Mode에서 다시 적용하려면 Mystery > UI > Apply MaruBuri + Pretendard Fonts를 사용합니다. Noto Sans KR 에셋도 보존되어 있습니다.

MaruBuri의 저작권과 SIL Open Font License 1.1은 MaruBuri-OFL.txt에 있습니다. Pretendard의 라이선스는 Pretendard-OFL.txt에 있습니다. Pretendard 원본은 공식 저장소의 7aeb0698819be2b4097dae8ec8fe6a795e5cf3ae 커밋에서 가져와 Git blob 해시를 대조했습니다.
