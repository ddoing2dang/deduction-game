# Gameplay presentation checkpoint

GameplayPresentation receives the existing public CharacterPresentation cues, applies a 1.2-second focus override and returns automatically to PcCameraController's existing tracking/three zoom levels. Pair actions focus the midpoint; solo actions focus their actor. Fixed camera rotation, game time and rule execution are unchanged. Win has priority over simultaneous Lose cues. Restart clears presentation state.

RuntimeGameUI creates a ScreenSpaceOverlay Canvas with 1920x1080 CanvasScaler, anchors, scrollable actions/public log/private information and a simple game-result/restart panel. The standard com.unity.ugui 2.0.0 package is the sole new UI dependency; no TMP, fonts, icons, images, controller clips or final designs were added. LegacyRuntime built-in font is temporary.

The Canvas calls existing GameManager public action methods. A small clamped selection setter shares the existing OnGUI selection fields; public read-only log/result properties expose no other player's private notes. Setup/turn controls use the existing phase/turn; individual action eligibility remains enforced by GameManager. Movement uses existing room selection/move calls. Role-specific ability guards stay in GameManager. Action controls scroll to expose all selections/analysis/culprit abilities. F10 or the developer button toggles the preserved debug OnGUI. UI pointer hits do not click through to RoomNode; wheel scrolling over UI does not zoom the map.
