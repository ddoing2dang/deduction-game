## 현재 코드 상태
기존 Unity C# 게임플레이는 **이전 6인 PvP 카드 기반 구현(LEGACY)**이며 새 기획을 만족하는 소스가 아니다. 카드·턴·능력·점수 코드는 사용자 요청에 따라 재설계할 예정이며, 현재는 기획 구조만 먼저 GitHub에 반영했다.

- 실제 Unity 프로젝트: `UnityProject/`.
- 기존 코드/씬/아트는 전체 백업 브랜치에 보존했고, 현행 브랜치에서도 새 구현 범위가 정해지기 전에는 무작위로 삭제하지 않는다.
- 별도 요청 없는 기능 테스트·빌드·배포를 실시하지 않는다.
