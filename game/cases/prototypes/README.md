# NPC 대사 문제 수정 — 구체적인 사건 증언 시범본

**2026-11-08 사용자 추가 확정:** 범인만 거짓 정보를 말할 수 있다. 3개 시범 사건 각각 범인 1명만 허위 알리바이 1개를 작성했고, 무고한 5명은 거짓말·기억오류·허위 목격을 허용하지 않는다. 데이터에는 `truthStatus`, `speakerRoleInThisSample`, `falseInformationAllowed`를 명시했다. 모든 TRUE_PROPOSED도 실제 사건 지식 및 동선 검증 전 승인된 사실 대사로 사용 불가. 상위 규칙은 `../culprit_only_deception_policy.v1.json`.


기존 228개+486개 대사는 실제 인과 사건/알리바이가 없어 "확인해 보자", "살펴보자" 같은 안내를 반복했으며, 이는 **증거를 얻는 NPC 심문 대사로는 부적절**했다.

## 시범본 (아직 실제 게임에 적용되지 않음)

- `evidence_driven_dialogue_cases.v1.json` — **호텔, 크루즈, 음악방송** 테마별 시범 사건 1개씩.
- 각 사건 **6 NPC × 알리바이/목격/물건 질문 각 1개 = 18개 사실형 대사**, 4개 독립 증거, 증거를 제시했을 때만 가능한 1개 모순 추궁 분기. 전체 **기본 진술 54개 + 추궁 3개 = 57개**, 증거 12개.
- 모든 대사에 **실제 시각·장소·본 것/못 본 것·자기가 아는 소지 물품**을 넣었다. 사건 진실과 구별된 **NPC 주장**이므로 거짓말을 객관 사실로 UI에 표시하지 않는다.
- 모순 추궁은 원 진술 `statementId` + 플레이어가 획득한 `evidenceId`가 있어야만 출력한다. AI가 임의로 범인을 알아내거나 새 사실을 만드는 용도가 아니다.
- 내부 NPC ID는 변경하지 않았고 표시 이름은 **마도아 / 마리예 / 나주아 / 복희 / 지로아 / 문이린**으로 연결한다.
- 범행 방식 4대 분류와 공통 12종 흉기·개인실당 3개 실물 제약은 그대로 유지한다.
- **범인과 사건 사실은 새로 쓴 시범 초안이지 승인된 원본 사건이 아님.** `authorOnly`의 정답·전체 동선은 NPC 응답 데이터/수사 기록에 직접 제공하면 안 된다.
- 이 3개 사건도 출입/반환 동선, 감식의 신뢰성, NPC 진술의 일치, 독립 증거, 정답 유일성, 사건 난이도 등을 아직 실제 솔버로 검증하지 않았다. **Unity/게임에 선택 가능으로 등록 금지**.
- 기존 원본 대사 **714개**, 선별본 **480개**는 보존. 이번 작업은 **추가 시범 사건 문서/데이터 작성**이며 기존 27개의 시나리오를 전부 고쳐 완료했다고 주장하지 않는다.
- 게임 코드 수정, 기능 테스트, 빌드, 배포 없음.

## 예시

예전: `그 시간 얘기지? 헷갈리지 않게 순서대로 확인하자.`

시범: `8시 12분쯤 1층 계단 앞에 있었어. 마도아랑 마주쳤지.`

**원칙:** 플레이어 질문 하나에 최소 한 개의 시간·장소·목격·물건 등 유효한 정보를 주되, 해당 NPC가 실제로 알고 있고 사건 사실이 승인된 것만 답한다.
