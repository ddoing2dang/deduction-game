직접 육안 확인한 대상은 현재 장미 대저택 UI PNG 9개, 공식 초상화 PNG 6개, 인트로 PNG 1개, 사건 기록 SVG 12개, 최종 추리 SVG 3개다. SVG는 저장된 파일을 Inkscape로 임시 래스터화해 확인했다. 이는 승인 PNG 원본 또는 Unity 렌더 결과와 동일하다는 뜻이 아니다. 과거 참고본은 파일 목록·분류·해시를 대조했으며 현재 승인본으로 승격하지 않았다.

원본이 없는 장소 단서·인물 수첩·최종 추리 픽셀 원본의 화질·장식·세부 여백은 **검증 보류**다. 맵 전체의 3D 아트, 모든 과거 개발 스크린샷, 다른 테마의 완성 품질은 이번 UI 점검의 합격 대상이 아니다.

## 2. 전체 결론

1. 현재 확인한 PNG 중 전면 재제작이 필수라고 확정할 이미지는 없다. 승인 레이아웃과 공식 얼굴·복장은 유지한다.
2. 먼저 필요한 작업은 **누락 원본 복구 → 최신 승인 흐름과 문서·코드의 충돌 정리 → 배경/문자/초상화/상태 분리 → 부분 보정**이다.
3. 이미지 파일이 있는 것과 Unity에서 승인 디자인으로 구현된 것은 다르다. 신규 UI PNG 9개는 `.meta`가 있으나 씬·프리팹의 직렬화 GUID 참조는 발견되지 않았다. 현재 `RoseMansionView`는 단색 동적 UI다.
4. 실제 사건 데이터의 42개 기본 슬롯은 모두 미승인·본문 공란이다. 6개 범인 분기의 수법·흉기 ID도 공란이다. **사건 개연성 완성, 유일해, 10턴 해결 가능성, 실제 난이도는 통과 판정을 내릴 수 없다.**
5. 코드에는 미완성 데이터 상태에서의 객실 진행 차단, 아이템 초과 선소모, 저장 실패 안내 덮어쓰기 등 별도 수정 대상이 있다. 승인 차단 장치 자체를 없애서 해결하면 안 된다.

장미 UI `asset_manifest.json`에 기재된 13개 파일은 모두 존재하고 SHA-256이 일치했다. 그중 current 6개·reference 7개이며, 로비 PNG 2개·시신 PNG 1개·로비 참고 PNG 1개는 이 manifest 목록에 포함되지 않는다. 이는 파일 누락이 아니라 **목록 보완 필요**다.

누락 PNG 원본은 장소 14 + 인물 6 + 최종 추리 2 = **기록으로 식별 가능한 최소 22장**이다. 사건 기록 SVG 12개는 실제 이미지이므로 누락 이미지로 세지 않는다. 흉기 수첩 등 개수가 확인되지 않은 자료도 이 22장에 임의로 더하지 않는다.

상세 파일별 규격·해시·메타 및 GUID 참조 수는 [정적 이미지 목록](ROSE_MANSION_UI_ASSET_INVENTORY_20261115.csv)을 참조한다.

### 소스상 유지되는 안전장치

- 조회한 슬롯 key를 `used`에 넣고 재조회 소모를 막는다.
- 한 턴에는 Search 기본 1회와 Question/Victim 기본 1회가 적용된다.
- 204호는 랜덤 잠금 후보에서 제외하고, 잠금 전 방문 가능 객실이 3개 이하이면 잠금을 만들지 않는다.
- 당일 방문 제한과 영구 소진을 구분하며 시간대가 비어도 P>0이면 즉시 조기 결말로 바꾸지 않는다.
- 모든 기본 슬롯과 6분기 준비가 끝나기 전 조사 본문을 차단한다. 일부 범인 분기만 준비된 차이로 정답이 노출되는 것을 방지하려는 장치다.
- 최종 3축 판정 함수는 범인 오답이면 오판, 범인 정답+다른 축 오답이면 부분 해결로 구분한다.
- 파일 교체 때 `.bak`을 남기는 저장 코드가 있다. 실제 디스크 I/O 신뢰성은 미검증이다.

위 항목은 코드 경로 확인이며 기능 테스트 합격 목록이 아니다.

## 9. 후속 수정 순서와 완료 조건

이 목록은 수정 제안이며 자동 실행·승인 요청이 아니다. 사용자가 지정하는 순서대로 수정한다.

1. **원본 복구:** 누락 PNG·흉기 수첩 자료의 실제 존재 확인, 기존 해시 대조. 승인본과 참고본 경로 유지.
2. **최신 규칙 정리:** D01~D05 처리. 실제 사건 진실·대사·단서는 별도 승인 전까지 비워 둔다.
3. **진행·기록 문제 수정:** B01·B03·B04 우선. 가짜 사건 데이터나 승인 우회 없이 진행 차단·아이템 손실·저장 안내를 해결.
4. **이미지 부분 보정:** V02~V07. 원본 대신 별도 파생본 사용, 공식 초상화 바이트·기존 GUID 보존.
5. **Unity 적용 준비:** 수첩 네 탭, 10턴, 세 단계 최종 추리의 요소·상태·데이터 바인딩 명세. 미획득은 `?`/`미획득`, 미진행 턴은 미진행으로 구분.
6. **콘텐츠 검수:** N01~N09·L01~L08에 맞춰 6분기별 실제 근거표와 무보너스 조사 경로 작성. 사건 내용을 승인받기 전 정답화 금지.
7. **실행 검증은 별도 요청 후:** 원본 확인·코드 검토·문서 저장만으로 Unity 기능/밸런스 검증 완료를 주장하지 않는다.
