# 검은 장미의 비밀 — 모바일 웹판

**PC Unity 프로젝트와 분리된 독립 2D 싱글플레이**입니다. 게임 소스 경로: `web/mobile/`.

## 웹 실행
- GitHub Pages: https://ddoing2dang.github.io/deduction-game/mobile/
- 로컬 테스트: `python -m http.server 8080`을 `web` 폴더에서 실행하고 `/mobile/` 열기
- 설치, 로그인, 서버 없이 HTML/CSS/JS로 구동. 진행 상황은 브라우저 localStorage에 자동 저장

## 모바일 전용 간편 규칙 (2026-11-03 업데이트)
- 6명 확정 캐릭터 이미지, 검은 장미 저택 9곳, 모바일 전용 예시 도구 9종
- **R1부터 R12까지** 진행. 화면 상단에 현재 R 번호, 12칸 진행 바, 현재 단계 노출
- **각 라운드에서 정보 행동 1회**. 가설 조사(범인·장소·도구 3종 동시 제출)는 사건 전체에서 **최대 3회**. 그 외 라운드는 NPC 의심·협조, 방별 증거, 정보형 능력 또는 행동 없이 종료를 선택
- 조사 결과는 세 가지 중 **정답과 일치하는 개수(0~3개)만** 알 수 있음. 어느 항목이 정답인지 알려주지 않음
- 조사 직후 **조사 완료/라운드 종료**로 표시되며 ‘R1 종료 → R2 시작’ 버튼을 직접 눌러야 다음 라운드가 시작됨
- **최종 추리는 R6부터** 가능. 전체 최대 2회, 같은 라운드에서는 1회만 가능. 첫 실패 후 다음 라운드부터 다시 지목 가능
- R12에는 최종 추리로 마무리하며, 마지막 지목이 틀리면 남은 재시도 횟수가 있더라도 라운드 종료로 패배 처리
- 추리 수첩에서 후보는 **플레이어가 직접** 제외 표시. 자동 후보 제거/자동 정답 계산 없음
- 로컬 기존 `blackrose.web.solo.v2` 저장 진행은 삭제 없이 R 진행 상태를 계산해 이전 데이터 사용 가능

**이 규칙은 모바일 독립판의 간편 규칙**이며 PC의 6인 AI/멀티, 라운드당 각 플레이어 턴, 목격정보/득점/능력 시스템을 구현한 것이 아닙니다.
PC판의 미확정 흉기 목록을 웹판 예시 도구 목록으로 확정하지 않습니다.


## 게임 시작 캐릭터 선택 (2026-11-03)
- 새로운 사건 시작을 누르면 **확정된 초상화 6장**을 3열 선택 화면에서 볼 수 있습니다.
- 인물 선택 시 카드가 강조되고 미리보기/이름이 표시됩니다. 선택하지 않으면 게임 시작이 불가능합니다.
- 선택한 캐릭터는 싱글플레이의 **플레이어 수사자**가 되며, **나머지 5명 중 하나가 범인**입니다. 이 모바일 독립판 설정은 PC의 고정 6인 역할 배분을 변경하지 않습니다.
- 본인 캐릭터는 조사/최종 지목 범인 목록에서 선택 불가, 인물 도감/추리 수첩에는 '내 캐릭터'로 표시됩니다.
- 화면에 플레이어 캐릭터 초상화를 지속 표시하고, 사회자 프롤로그에서 캐릭터 이름을 언급합니다.
- 캐릭터 정보는 기존 로컬 저장 키에 함께 저장되므로 페이지를 다시 열어도 복원됩니다.
- 기존 캐릭터 미선택 상태로 시작한 **구버전 저장 게임은 그대로 이어하기 가능**하며, 새 사건부터 캐릭터 선택을 적용합니다.
- 원본 캐릭터 그림은 다시 그리지 않고 기존 승인된 `assets/characters/*.webp` 이미지 파일을 그대로 재사용합니다.

## AI 수사/이동/이벤트 확장 (2026-11-03)

- 새 사건 시작 시 **플레이어 캐릭터에게 랜덤 능력 8종 중 하나** 부여. 각 능력은 실제 이동, 정보 행동, NPC 심문, 이동 방해 무시 등에 작동하며 사용 횟수 제한이 있음.
- 선택한 플레이어 외 **5명의 NPC도 각각 랜덤 능력 8종 중 하나와 행동 성향**을 부여받음. NPC는 라운드마다 이동하고 일부 능력(질주·도약·우회·회귀·정보 수집)을 실제 행동에 활용. 같은 방에 있을 때 능력/성향을 볼 수 있으며 협조 확률도 다름.
- 플레이어 이동은 기본 **라운드당 2P**. 방은 연결된 경로에서만 갈 수 있고 2P 이상 먼 방은 바로 이동할 수 없음. 지도에 이동 가능한 방이 강조 표시됨.
- **같은 방의 NPC를 만나야만 의심/협조**할 수 있음. 한 라운드 정보 행동은 가설 조사(최대 3회) / 의심(최대 3회) / 협조(최대 1회) / 방별 특별 단서 / 정보형 능력 중 하나.
- NPC 보유 카드는 정답에서 제외된 장소와 도구 카드. **의심을 누르면 특정 NPC에 대해 의심할 장소 1곳과 흉기 1종을 모두 직접 선택**. 선택 장소는 현재 서 있는 방과 달라도 됨. 상대가 해당 카드 중 1장 이상 보유하면 그중 1장만 공개하며, 둘 다 없으면 없다고 알림. 의심 성공·실패 모두 1회 및 이번 라운드 정보행동 1회를 소비. UI에서 선택이나 의심을 취소하면 횟수 소비 없음. NPC와 같은 방에서만 의심 가능. 협조는 수락 시 카드 한 장을 공개하고 거절 시 행동권을 차감하지 않음.
- 플레이어 1명분 손패 장소·도구 1장씩 배분, 별도의 미배분 장소/도구 카드 2장씩 존재. 단서 카드의 진위 판정은 정답을 바꾸거나 거짓 정보를 생성하지 않음.
- **범인의 비공개 방해:** R2~R11 중 일정 확률로 각 종류 최대 2회까지 연막(정보행동 제한), 통로 잠금(추가 이동력), 조사 통신 교란(결과 다음 라운드 발표) 중 하나 발동. 범인 이름을 이벤트 UI에 표시하지 않음.
- **특별 이벤트:** 일부 방의 일회용 증거, R2~R4 열쇠, 열쇠 후 R5~R7 비밀상자. 해당 방에 방문해야 수집 가능하고 비밀상자는 정답 아닌 미배분 카드 2장 제공.
- **목격정보:** R3/R6/R9/R12 시작에 실제 범인의 현재 방을 포함한 **4개 후보 방**을 공개. 목격정보는 실제 NPC 위치에 기반하므로 거짓 확정정보를 생성하지 않음.
- 정보행동이 막히거나 전략상 필요하면 **행동 없이 이번 라운드 종료**를 선택할 수 있음.
- 라운드/손패/NPC 위치/가설 조사 횟수/무작위 능력 횟수/이벤트 상태/추리 수첩을 브라우저 로컬에 저장.
- 프롤로그, NPC 연출, 사건 판정은 미리 작성된 대사/로직을 사용. 실시간 생성형 AI, 실시간 서버 멀티플레이 또는 PC판 전체 능력/카드/점수제를 구현했다고 주장하지 않음.
- **주의:** 별도 모바일 간편판용 밸런스·미스터리 게임 규칙. 기존 PC Unity의 검증된 룰, 3D 캐릭터, 파일을 변경하지 않음.

## 사회자·시네마틱 연출 (2026-11-03)
- **사건 도입 프롤로그:** 새 게임 시작 시 장미 저택의 사회자가 사건을 안내하며 시작
- **라운드 전환:** R1~R12 각각의 연출 문구 / R6 최종 추리 개방 / R12 마지막 라운드 강조
- **조사 판정:** 범인·장소·도구 조합을 직접 선택한 뒤 일치 항목 개수만 사회자가 발표, 어떤 항목인지는 비공개
- **최종 판정:** 정답 성공 / 첫 실패 / 2회 실패 또는 R12 종료를 별도 사회자 장면으로 발표
- **맵 연출:** 9개 방마다 간략화된 장식 패널과 분위기 색, 화면 등장 모션
- **인물 연출:** 승인된 초상화 여섯 장을 사용한 전체화면 캐릭터 대화. 인물 초상화 터치 후 일반 대사 확인, 해당 인물을 선택형 조사 가설에 바로 입력 가능 (라운드 조사가 남은 경우)
- **UI:** 사회자 안내 스트립, 라운드 진행 바, 미스터리 다이얼로그, 터치 반응, 작은 화면 및 모션 최소화 접근성
- **연출 넘기기:** 팝업 '계속' / '모든 연출 건너뛰기'. 대사 다시 보기는 사회자 스트립 버튼
- **음성:** 사용자가 누르는 '사회자 음성 듣기' 버튼으로 브라우저 내장 한국어 TTS를 시도 (기기별 지원/발음 차이 있음). 전문 녹음 음성이 아니며 자동 재생하지 않음
- **중요:** 사회자/대사/모든 인트로는 `사전 작성된 연출`. 실시간 생성 AI 사회자가 아니며 정답 관련 미확정 단서, 부정확한 목격증언을 만들어내지 않음. 캐릭터는 고정 6명만 유지.
- **기술:** HTML/CSS/JavaScript만 사용. 진행상태는 기존 브라우저 localStorage 저장을 유지. 기존 PC Unity 프로젝트 불변.
