# Six character images required for complete visual presentation
This GitHub branch currently contains source code and placeholders but DOES NOT contain the approved character image binaries.
Use the provided `Black_Rose_Mobile_Godot_Prototype.zip` (which includes original bytes + game-ready true PNG copies) and copy these six files to this directory:
- CHR_MARIHI.png
- CHR_JIRO.png
- CHR_NAZ.png
- CHR_MATTO.png
- CHR_BOKI.png
- CHR_MUNIRE.png

Do not regenerate or replace them. Missing images display name-only fallbacks. The mobile ZIP is the complete reference package; the GitHub source script implements the same basic deduction mechanics, with a simpler UI.
